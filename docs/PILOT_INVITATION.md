# External Reviewer Invitation

Use this invitation with people who did not contribute to the repository. Ask for a short independent attempt; do not provide setup hints before they begin.

> I built an open source AI vendor assurance project and would value a 15-minute first-time reviewer test. Could you start from the [repository](https://github.com/giselleevita/vendor-red-team-passport), run `make reviewer-demo` in a clean checkout, then find the synthetic Passport, explain its release-gate result, and identify one limitation? No API key or private data is needed. Please include any point where you got stuck. You can use the [feedback form](https://github.com/giselleevita/vendor-red-team-passport/issues/new?template=adoption-pilot.yml) or reply privately. I will only publish anonymized observations with your consent.

After the participant finishes, follow the questions and evidence rules in [the pilot protocol](ADOPTION_PILOT.md). Do not share the project's expected answers in advance.
