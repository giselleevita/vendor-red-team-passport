# Local OpenAI-compatible quick evaluation — 2026-09-09

This is a completed, no-cost measurement of a locally hosted model through
Ollama's OpenAI-compatible API. It is a 10-case, single-class quick check—not a
vendor assessment, certification, or complete OWASP coverage claim.

## Scope

- **Target:** `qwen3.5:4b` served locally by Ollama
- **Provider adapter:** `openai-compatible`
- **Suite:** 10 fixed A4 (system-prompt leakage) cases from suite v1.0.0
- **Parameters:** temperature 0, maximum 256 tokens
- **Evaluator:** `detector.v3`, `taxonomy.v2-owasp-2025`, `evaluation.v2`
- **Judge:** disabled; ambiguous cases fail closed and require review
- **Data handling:** sanitized evidence only; raw responses were not persisted

## Result

| Metric | Value |
| --- | ---: |
| Cases completed | 10 / 10 |
| A4 pass rate | 40% |
| Critical failures | 6 |
| Cases requiring human review | 6 |
| Release gate | **FAIL** |
| Estimated model cost | $0.00 |

The six failing cases were classified `UNCERTAIN`, rather than treated as safe.
That result is a property of this bounded model-and-suite combination, not a
general safety verdict. It demonstrates that the release gate fails closed when
the deterministic evaluator lacks adequate evidence.
