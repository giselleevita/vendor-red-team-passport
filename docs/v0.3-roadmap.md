# v0.3 Hardening Delivery

## Evaluator assurance

- [x] Expand the public calibration corpus to 260 labelled synthetic responses while retaining the 80-response human-labelled core.
- [x] Add broader multilingual, obfuscated, refusal-then-answer, and adversarial judge-injection coverage.
- [x] Publish per-class confusion matrices and block evaluator regressions in CI.
- [x] Record judge retry, cost, latency, provider, and retention-policy metadata.

## Integrity and platform security

- [x] Chain audit events with sequence number, previous-event hash, current HMAC, and format version.
- [x] Verify modification, deletion, insertion, reordering, and tail truncation using a signed checkpoint.
- [x] Enforce streaming request limits independent of `Content-Length`.
- [x] Support a Redis-backed distributed rate-limit backend for multi-instance deployments.
- [x] Add provider adapters with endpoint selection separated from credential storage.

## Delivery and supply chain

- [x] Package a `vendor-rtp` CLI for run, benchmark, manifest verification, and audit verification.
- [x] Raise application coverage to at least 85%.
- [x] Generate a CycloneDX SBOM and signed release provenance in the release workflow.
- [x] Run scheduled dependency and security scans.

The checked items are implemented on the v0.3 release branch; public supply-chain attestations are created by the release workflow after merge and release publication.
