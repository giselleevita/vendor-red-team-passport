# v0.3 Hardening Roadmap

## Evaluator assurance

- [ ] Expand the public calibration corpus to at least 250 labelled responses.
- [ ] Add broader multilingual, obfuscated, refusal-then-answer, and adversarial judge-injection coverage.
- [ ] Publish per-class confusion matrices and block evaluator regressions in CI.
- [ ] Record judge retry, cost, latency, provider, and retention-policy metadata.

## Integrity and platform security

- [ ] Chain audit events with sequence number, previous-event hash, current HMAC, and format version.
- [ ] Verify modification, deletion, insertion, and reordering.
- [ ] Enforce streaming request limits independent of `Content-Length`.
- [ ] Support a distributed rate-limit backend for multi-instance deployments.
- [ ] Add provider adapters with endpoint selection separated from credential storage.

## Delivery and supply chain

- [ ] Package a `vrtp` CLI for run, benchmark, manifest verification, and audit verification.
- [ ] Raise application coverage to at least 85%.
- [ ] Generate a CycloneDX SBOM and signed release provenance.
- [ ] Run scheduled dependency and security scans.

No item is presented as implemented until its tests and release evidence are merged.
